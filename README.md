## 🚀 How to Deploy on GitHub Pages

1. Create a new GitHub repository (e.g. `rakib-portfolio`)
2. Upload all files keeping the folder structure:
   - `index.html` → root
   - `images/` folder → root
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch → `/ (root)`
5. Click **Save**
6. Your site will be live at `https://YOUR-USERNAME.github.io/rakib-portfolio`

## ✏️ How to Update Content
- Edit `index.html` directly in GitHub's web editor
- To add new photos: upload to `images/` folder, then reference as `images/yourphoto.jpg`
